## CTFStyle-portfolio

A CTF-inspired personal portfolio built with plain HTML, CSS, and JavaScript.

Instead of the usual green-on-black hacker theme, I wanted something that felt closer to a real CTF: an interactive terminal, a boot sequence, and a clean blue/red color palette.

No frameworks, no build tools—just open `index.html` and it works.

## Features

- Interactive terminal
- Boot sequence
- Hidden commands and easter eggs
- CTFtime competition log
- Formspree contact form
- Vanilla HTML, CSS, and JavaScript

## Running

```bash
git clone https://github.com/HexFud/sec-portfolio.git
cd sec-portfolio
python3 -m http.server 8000
```

Or simply open `index.html`.
